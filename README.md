# Car Price Prediction

## Project Overview
Machine learning model to predict used car prices.

## Objective
To estimate selling price based on car features.

## Dataset
Dataset containing car details like year, mileage, fuel type, etc.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Model Used
- Linear Regression / Random Forest

## Key Insights
- Newer cars have higher value
- Mileage affects price negatively
